# trade-log-comments

**このリポジトリはコメントの置き場です。サイトのコードは入っていません。**

「場帳 — SYSTEM TRADE LOG」（個人の自動売買の記録サイト）のコメント欄は
[giscus](https://giscus.app/ja) を使っていて、書き込まれた内容はこのリポジトリの
[Discussions](https://github.com/Shunta7215/trade-log-comments/discussions) に保存されます。

サイト本体のリポジトリは private です。private のままだと訪問者が Discussions を読めず
giscus が成立しないため、**コメントのためだけに public なこのリポジトリを分けています**。

## コメントの方針

- コメントは**サイト全体で1つのスレッド**にまとまります。日ごとには分かれません。
- **個別銘柄の見通しや、売買の相談にはお答えしません。** 投資助言にあたるためです。
  返信がないのはそのためで、無視しているわけではありません。
- サイトに載せているのは運用者自身の売買記録で、**投資助言・推奨ではありません**。
- 誹謗中傷・宣伝・個人情報を含む書き込みは削除します。

## 中身

コメントの実体は Discussions にあります。このリポジトリのファイルはこの README だけです。
